# 📦 WordPress Custom Plugins Collection

This package contains custom-developed WordPress plugins designed to enhance WooCommerce functionality, improve user experience, and add business-specific features.

---

## 📁 Included Plugins

### 1. **Checkout Progress Bar**

Adds a visual progress bar to the WooCommerce checkout page to improve user experience and reduce cart abandonment.

**Features:**

* Step-based checkout indicator (Cart → Checkout → Order Complete)
* Fully responsive design
* Easy integration with WooCommerce
* Lightweight and fast

**Usage:**

* Install and activate the plugin
* Automatically appears on the checkout page

---

### 2. **Custom WhatsApp Button**

Displays a floating WhatsApp button for instant customer communication.

**Features:**

* Floating button (desktop + mobile)
* Customizable phone number & message
* Option to open in new tab
* Simple UI settings

**Usage:**

* Install and activate the plugin
* Configure WhatsApp number from settings panel

---

### 3. **Safe WooCommerce Order Export**

Allows secure export of WooCommerce order data.

**Features:**

* Export orders in CSV format
* Filter by date, status, or customer
* Secure and optimized export process
* Admin-only access

**Usage:**

* Install and activate the plugin
* Go to WooCommerce → Safe Order Export
* Select Generate CSV Button and download file

---

### 4. **Video Play on Product Page**

Adds video playback functionality directly on WooCommerce product pages.

**Features:**

* Add video to product gallery or custom section
* Auto-play and replay options
* Mobile-friendly with close/hide button
* Lightweight player integration

**Usage:**

* Install and activate the plugin
* Add video URL or upload from product edit page video_url section
* Configure playback settings

---

## ⚙️ Installation

1. Go to **WordPress Admin Panel**
2. Navigate to **Plugins → Add New**
3. Click **Upload Plugin**
4. Upload the ZIP file
5. Click **Install Now**
6. Activate the plugin

# WordPress Custom Plugins Collection

This repository contains four custom WordPress plugins designed to enhance WooCommerce functionality and improve customer experience.

---

## Included Plugins

### 1. Checkout Progress Bar

Adds a visual progress bar to the WooCommerce checkout process.

Features:
- Step-based progress indicator: Cart → Checkout → Order Complete
- Responsive design
- Lightweight and easy to integrate
- Helps reduce cart abandonment

Usage:
- Install and activate the plugin
- The progress bar appears automatically on the checkout page

---

### 2. Custom WhatsApp Button

Displays a floating WhatsApp button for instant customer contact.

Features:
- Floating button for desktop and mobile
- Custom phone number and default message
- Option to open chat in a new tab
- Simple settings panel

Usage:
- Install and activate the plugin
- Configure the WhatsApp number and text in plugin settings

---

### 3. Safe WooCommerce Order Export

Allows secure export of WooCommerce order data.

Features:
- Export orders in CSV format
- Filter by date, order status, or customer
- Optimized export process
- Accessible to admin users only

Usage:
- Install and activate the plugin
- Go to WooCommerce → Order Export
- Choose filters and download the CSV file

---

### 4. Video Play on Product Page

Adds video playback capability to WooCommerce product pages.

Features:
- Add video to the product gallery or a custom product section
- Auto-play and replay support
- Mobile-friendly with close/hide controls
- No black side spacing issues
- Lightweight player integration

Usage:
- Install and activate the plugin
- Add a video URL or upload a file from the product edit screen
- Adjust playback settings as needed

---

1. Go to WordPress Admin Panel

4. Upload the ZIP file

6. Activate the plugin
